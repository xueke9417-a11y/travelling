# 行程规划助手 MVP

在聊天中澄清旅行需求，确认真实地点后生成每日往返路线、天气提示和可复算预算。

## 已实现

- DeepSeek + Agno 多轮需求澄清；也可直接填表，不依赖模型完成路线查询。
- 高德城市内 POI 搜索，用户核对地点名称、地址、坐标后选择。
- 按地理邻近分组，每日最多两个景点；逐段查询自驾/公共交通的距离、预计耗时和收费。公交显示返回的线路名称。
- 每天从同一住宿/出发点出发并返回，计入全部往返路段；默认城市中心仅为可替换参考点。
- 高德天气预报按行程日期匹配，雨雪提示与衣物建议；无预报不推测数值。
- 预算以 Python Decimal 计算，调整费用或人数即时重算；超支提示、数据缺失提示、JSON 下载。
- 120 秒工作流软截止（当前 HTTP 请求可能再耗时数秒），单请求连接/读取超时、每会话短时内存缓存、失败后保留可用结果。

## 当前范围

支持 **1–7 天、单个城市或区域、同一住宿点每日往返**，不是跨城市环线规划器。每次最多搜索 6 个景点名称、最多选择每天 2 个/全程 14 个景点。景点少于天数时，空出的日期显示自由活动。

分组使用地理邻近启发式，不保证最优路线。每景点 2 小时是提醒行程是否过满的假设，未查询开放时间。未来行程的交通时间是查询时估计；公交运营时间、山区天气、景区开放情况需出发前确认。

组合出行应明确选择本段主要方式。跨城机票/火车票、订票订房、实时门票、地图可视化及 PDF 不在本版内。

## 环境与启动

Python 3.10+。依赖见 `requirements.txt`。

从仓库根目录执行：

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
& .\.venv\Scripts\python.exe -m streamlit run app.py
```

浏览器打开终端显示的本地地址。CLI `main.py` 仍仅提供澄清对话；完整规划在网页中。

复制 `.env.example` 为 `.env`，填入自己的密钥；程序启动时自动读取仓库根目录的 `.env`，也接受进程环境变量：

| 变量 | 用途 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 聊天澄清；不填时仍可直接使用表单 |
| `DEEPSEEK_MODEL` | 你所用 DeepSeek 端点支持的模型名 |
| `AMAP_API_KEY` | 高德 Web 服务：地理编码、POI、路线、天气权限 |

不要把真实密钥复制进 README、截图或代码；不要将 `.env` 提交到 Git（已在 `.gitignore` 中排除）。

## 演示

1. 输入“2026 年 10 月 8 日到 9 日去成都自驾”（请替换为当前有效日期），或直接填表。
2. 查询“成都杜甫草堂博物馆”和“武侯祠博物馆”，核对地点后选择。
3. 可填写酒店名称作为每日出发点；留空则使用城市中心参考点。
4. 点击生成，查看往返路线、天气与预算；修改左侧每日餐饮金额，预算立即更新。

## 预算口径

- 自驾：路线米数 ÷ 1000 ÷ 100 × 油耗（升/百公里）× 油价 + 高德过路费 + 额外交通费。
- 公交：高德返回的全程票价 × 人数 + 额外交通费。没有查询到票价时保持未知，不代填零。
- 餐饮：全组每日餐饮 × 天数；住宿：全组每晚住宿 ×（天数 − 1）；门票：全组手填总额。
- 默认餐饮 300 元/天、住宿 300 元/晚、油耗 8 升/百公里、油价 7.5 元/升都是可编辑假设。门票与额外交通费默认 0 代表未填写，不代表免费。
- 缺少任一路线/费用时不显示确定的总预算，不推断“未超支”。

## 测试

```powershell
& .\.venv\Scripts\python.exe -B -m unittest test_planner test_app -v
```

离线测试隔离 HTTP，不需要密钥、不产生模型费用；覆盖日期校验、预算公式、未知费用、天气兜底、API 错误脱敏和页面生成/重算/重置。

联网验证使用实际 API，会消耗账号额度。自动测试不是对所有城市或未来预报的保证。

## 文件

- `main.py`：需求澄清和结构校验。
- `services.py`：高德接口与响应转换。
- `planner.py`：路线编排与预算纯计算。
- `app.py`：交互和结果展示。
- `test_planner.py`、`test_app.py`：离线回归测试。

技术依据：[高德路线文档](https://lbs.amap.com/api/webservice/guide/api/direction)、[POI 搜索文档](https://lbs.amap.com/api/webservice/guide/api-advanced/search)、[天气接口文档](https://lbs.amap.com/api/webservice/guide/api/weatherinfo)。
